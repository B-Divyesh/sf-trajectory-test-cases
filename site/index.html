03 How it works

Check agent calls in three steps

01

Record scrubbed events

You supply the argument scrubber. The recorder stores its output, not the raw arguments.

02

Declare partial order

Name required actions, attach only meaningful “after” edges, and forbid dangerous calls.

03

See why a fixture failed

Get stable exit codes, structured JSON, and a line-by-line trace that explains the mismatch.

04 Package API

Four library tools

Use the recorder, matcher, fault injector, or renderer independently. The package has no runtime dependencies.

Read the full API →
agent.test.ts
import {
  checkTrajectory,
  createRecorder,
  injectRetryFault
} from "trajectory-test-cases";

const trace = createRecorder({
  scrubArgs: (tool, args) => redact(args)
});

const result = checkTrajectory(
  fixture,
  trace.events()
);

expect(result.pass).toBe(true);
