Privacy.

Your traces stay on your machine. The browser checker does not upload fixture text, event traces, or clipboard contents.

Data we process

The site has no analytics, accounts, cookies, or third-party runtime scripts. It keeps your theme preference in local storage.

Demo edits use session storage keys prefixed with demo:. Resetting or leaving the demo deletes its workspace key.

The npm package

The library and CLI contain no telemetry or network client. The CLI reads only the fixture and event paths you provide.

Hosting logs

Our hosting provider may retain security logs such as IP address, requested path, and user agent. We do not build behavioral profiles from them.

Your choices

Clear local storage to remove the saved theme. Send privacy questions to privacy@sociobot.in.
